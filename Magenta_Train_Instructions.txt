Instructions for command line code for training magenta models



1) Convert MIDI Data to Note_Seq
Update input directory to where the midi data is stored

convert_dir_to_note_sequences ^
  --input_dir=C:\Users\adamc\MusicGenAI\MIDI\Artist_MIDI\<ARTIST NAME> ^ 
  --output_file=/tmp/notesequences.tfrecord ^
  --recursive

2) Extract Melodies (config can be attention, basic, mono, or lookback rnn) based on Magenta architecture desired

melody_rnn_create_dataset \ ^
  --config=attention_rnn \ ^
  --input=/tmp/notesequences.tfrecord \ ^
  --output_dir=/tmp/melody_rnn/sequence_examples \ ^
  --eval_ratio=0.10

3) Train model with note sequence dataset. Can update training steps, batch size, and RNN layers

melody_rnn_train \ ^
  --config=attention_rnn \ ^
  --run_dir=/tmp/melody_rnn/logdir/run1 \ ^
  --sequence_example_file=/tmp/melody_rnn/sequence_examples/training_melodies.tfrecord \ ^
  --hparams="batch_size=64,rnn_layer_sizes=[64,64]" \ ^
  --num_training_steps=20000


4) In seperate terminal, run the below code to track the model as it trains
tensorboard --logdir=/tmp/melody_rnn/logdir

Then open http://localhost:6006

5) If you wish to stop training, run the following in the training terminal
Ctrl + C
